Better Containers Category Editor

Better Containers keeps these files in %USERPROFILE%\Zomboid\Lua\BetterContainers In the Open or Save window, paste the path into the address bar or file name box and press Enter to jump there.
Server Economy's ATM pays each item's value × this percent (your server's SellValuePercent) × the item's category percents.
Better Containers leaves items with these script categories alone and ignores overrides for them. Match this to your Mod Options setting; the mod's default is Lore.

Default is the category Better Containers picks by itself. It is worked out here from the mod's rule files and the item scripts, so a few may differ from the game. Resetting an item removes your override and the game works out the true default.

The item list is the base game plus the mods you pick with Mods…. Overrides for items that aren't in those mods are kept and show as "Not in these mods".

    Save to the game

    Close Project Zomboid first. Better Containers reads these files once when it starts and writes its own copy back when you change a category in game, so edits made while it runs are lost.
    1. Download BetterContainers.zip. It holds both files inside a BetterContainers folder.
    2. Extract it into %USERPROFILE%\Zomboid\Lua and choose to replace the existing files.
    3. Start the game. Your categories load with Better Containers.

    Reset Stockroom books and magazines

    Load your Stockroom save. Every skill book and recipe magazine in your safehouse snapshot that you've put in a ValZom category goes back to its Better Containers default. Nothing changes until you press Reset.

    Stockroom saves in %USERPROFILE%\Zomboid\Lua\Stockroom, two files per character on each server (names ending in -a.txt and -b.txt). Select both; the newer one is used. The game writes them on the PC where you used Stockroom.

    Your server's ATM settings

    The ATM's prices depend on your server's Server Economy sandbox settings (sell %, category percents, gun buyback percents). Paste them here: the server console's sandbox list, SandboxVars.lua or servertest_SandboxVars.lua all work. Only the ATM settings are kept, in this browser.
